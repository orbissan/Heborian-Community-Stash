# Contributing

Bug reports and contributions are welcome. This is an early release intended for small groups sharing one server.

## Report a bug

Include the mod version, SPT version, relevant other mods, steps to reproduce, expected behavior and actual behavior. Screenshots and small log excerpts help. Remove personal information and do not publish profiles, credentials or complete server data.

## Make a change

1. Fork the repository and create a branch for your change.
2. Follow the [build guide](docs/BUILDING.md).
3. Keep changes focused and preserve existing item data and server-side validation.
4. Run the relevant verification and test inventory changes in an isolated game/server installation.
5. Open a pull request explaining the change, tests performed and remaining limitations.

Never commit game assemblies, generated packages, player profiles, warehouse data or local configuration. Contributions should be compatible with the project's MIT license.
